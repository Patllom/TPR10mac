# Module 6B — Task 7: หน้าจัดการที่เก็บรูปลงเวลา

สถานะ: Task 7 ผ่านการตรวจรับ Test, Build, Lint และ Code Review แล้ว มีข้อสังเกตระดับ Minor หนึ่งรายการตามด้านล่าง ไม่ได้หมายความว่า Module 6B ทั้งหมดหรือ NAS จริงผ่านการตรวจรับ

## สิ่งที่เพิ่ม

หน้า `/portal/admin/attendance-storage` และเมนูสำหรับบัญชีที่มี `attendance:storage-manage` โดยเฉพาะ ใช้ session/MFA เดิม ผู้ดูแลระบบไม่ได้สิทธิ์นี้หรือสิทธิ์ดูภาพโดยอัตโนมัติ

- เลือก alias ที่ Operations เตรียมไว้เพื่อลงทะเบียน ไม่มีช่องพาธหรือข้อมูลเข้า NAS
- ตรวจความพร้อม เปลี่ยนปลายทางรูปใหม่ เริ่มย้าย และดำเนินงานที่ติดขัดต่อ โดยส่งเหตุผลและเวอร์ชัน
- แสดงสถานะที่เก็บ สุขภาพ พื้นที่ว่าง และจำนวนรายการย้าย/ตรวจแล้ว/ติดขัด ไม่มีรูปย่อหรือปุ่มลบ
- เตือนว่ารูปเก่ายังอยู่ต้นทาง และไม่ควรถอดหรือลบต้นทางก่อนย้ายและตรวจครบ
- ต้นทางและปลายทางที่เลือกจากคนละหน้ายังคงอยู่ โดยโหลดหน้าที่เกี่ยวข้องใหม่พร้อมกันก่อนแสดงข้อมูล ทุก mutation ยังตรวจเวอร์ชันที่ API
- ปิดปุ่มเปลี่ยนปลายทางเมื่อ readiness ไม่ทราบ หมดอายุ หรือปิดรับรูปใหม่

## การรักษาข้อมูลส่วนตัวและผลลัพธ์ไม่แน่นอน

อ่านข้อมูลแบบ `no-store` พร้อม abort/ลำดับคำขอ หน้าจอไม่แสดงร่างจนข้อมูลที่ต้องใช้กลับมาครบ ใช้ ScopeFrame เดิมตรวจ session เมื่อกลับแท็บหรือ focus และทิ้งร่างเมื่อออกจากระบบหรือเปลี่ยนบัญชี

503 ไม่บังคับออกจากระบบ แต่ซ่อนข้อมูลและให้โหลดใหม่ 409 โหลดเวอร์ชันใหม่โดยไม่ส่ง mutation ซ้ำ หากเริ่มงานย้ายแล้วผลไม่แน่นอน จะระงับการเริ่มงานใหม่ในหน้าปัจจุบันและให้ตรวจรายการงานกับผู้ดูแล ไม่มีการลองใหม่ด้วย request ID ใหม่อัตโนมัติ

## การตัดสินใจและขอบเขตหลักฐาน

- ใช้ตัวแบ่งหน้าร่วมกับตัวเลือกที่จำหน้าต้นทาง/ปลายทาง แทนเพิ่มตัวแบ่งหน้าสองชุด เพื่อแก้การเลือกข้ามหน้าโดยไม่โหลดทุกรายการ ผลกระทบคือมีคำขอเพิ่มได้สองหน้าต่อรอบและต้องรอให้ครบ
- การทดสอบ HTTPS ใช้ login/MFA/session/proxy จริง และจำลองคำตอบ storage สำหรับการเปลี่ยนเวอร์ชัน ความพร้อม และ outage ที่ต้องควบคุมลำดับ ส่วน API/สิทธิ์ดูภาพและเพิกถอนสิทธิ์ตรวจด้วย integration tests ฐานข้อมูลจริง ไม่อ้างผลจำลองเป็น NAS จริง
- ไม่เพิ่ม API สำหรับอัปโหลดหรือเผยแพร่หลักฐานทดสอบใน production และไม่เปลี่ยน implementation backend ของ Tasks 1–6
- ผู้ตรวจไม่ได้รันทดสอบและไม่ได้ตรวจ NAS/load/backup/restore ของ Task 8 ผู้ดำเนินงานรับผิดชอบผลรันจริงและการแก้หลังตรวจ ไม่มีการอ้าง review แทนผล Test/Build/Lint
- ยังไม่ทำ Task 8 หรือ Module 6C ไม่ mount NAS จริง ไม่ push/merge และไม่ย้ายโค้ดเข้า checkout เดิม
