# รายงานตรวจรับ Module 7D — Task 14

ขอบเขต: ปิดคำขออัตโนมัติเมื่อสะสางครบ และอ่านยอดรายคำขอ/ทั้งชุดตามสิทธิ์

## สิ่งที่เปลี่ยน

- เพิ่มบริการปิดและ worker ตรวจคำขอเป็นชุดจำกัด ตรวจข้อมูลปัจจุบันภายใต้ family/request lock ก่อนปิด พร้อมประวัติและเวอร์ชันในธุรกรรมเดียว ล้มแล้วลองใหม่ไม่สร้างประวัติปิดซ้ำ
- ตรวจวันจบงานที่ยืนยัน ส่งครบ ยอดเงิน ค่าใช้จ่าย เงินคืน รายการรอตรวจ งวดจ่าย การกันวงเงิน ภาระส่วนขาด ส่วนเกิน และเหตุระงับ ยอดศูนย์อย่างเดียวไม่ทำให้ปิด
- แยกคำขอปิดแล้วออกจากภาพรวมทั้งชุด ส่วนเพิ่มเดิมหรือเคสปรับปรุงที่ค้างทำให้ภาพรวมยังไม่เสร็จ ไม่เปิดคำขอเดิมกลับ
- เพิ่มบริการอ่านยอดตามสิทธิ์ปัจจุบัน รายงานข้อมูลไม่ครบเมื่อเห็นเพียงบางคำขอ และรวมเฉพาะยอดที่มีสิทธิ์ ไม่เผยยอดซ่อนผ่านผลรวม
- เพิ่ม migration สำหรับประวัติการปิดโดยระบบโดยเฉพาะ แยกจากประวัติผู้ใช้เดิม ไม่สวมบัญชีผู้ใช้ ไม่เปลี่ยนสัญญา receipt ของคำสั่งอื่น และคงข้อบังคับลำดับส่วนเพิ่มของ Task 13

## หลักฐานการพัฒนาและตรวจ

ผู้ลงมือ Avicenna ใช้ TDD โดย behavioral RED คาดว่าคำขอเปลี่ยนเป็น Closed แต่ยังเป็น Approved; compile/fixture failures บันทึกแยก ไม่ใช้แทน behavioral RED

ชุดเฉพาะผ่าน 35/35 เคส ครอบการชนกับรับคืน/แก้คืน/เตรียมส่วนขาด การปิดซ้ำ worker ล้มตอน commit แล้วลองใหม่ สิทธิ์และยอดที่ซ่อน รวม migration และประวัติเดิม

ชุดผลกระทบรอบแรกผ่าน 215/216 เคส เคสล้มเป็น legacy fixture เขียน actor_kind ลง schema เก่า แก้เฉพาะ INSERT ให้ใช้คอลัมน์ประวัติเดิมโดยคง assertions แล้วตรวจ Task 13 และ Task 14 รวมผ่าน 56/56 เคส ไม่เปลี่ยนผลรอบล้มเดิมให้เป็นผ่าน

ผู้ตรวจอิสระ Zeno ให้ Spec PASS / Quality Approved ไม่พบ Critical/Important พบ Minor เรื่อง restart test ที่ไม่รอ worker tick จึงแก้เฉพาะเทสต์ให้ worker instance ใหม่ประมวลผล durable candidate จริง พร้อมตรวจประวัติเดิมไม่เปลี่ยน ผ่าน focused 1/1 และ Task14 35/35 ผู้ตรวจซ้ำยืนยัน T14-REVIEW-M1 = ADDRESSED ไม่มีปัญหาใหม่

คง T14-REVIEW-M2 เรื่อง EF Query[10102] และ SQL noise ร่วมกับ Minor log เดิม ไม่อ้างว่า log ไม่มี warning เทสต์ restart ครอบ replacement worker/provider instance ไม่ใช่ OS process kill/relaunch

## ข้อจำกัดและรายการติดตาม

งานนี้เป็นบริการภายในและ worker ส่วน API/client อยู่ Task 15 ยังไม่เริ่ม ไม่มีการ migrate ฐานจริง/push/merge คง M2-R1/R2-C1, HTTPS 504, Minor log, OpenAPI 500, T13-M1/T14-M1, T4-M1/T11-M1 สำหรับ Task 18 และ T12-M1/T13-REVIEW-M1 ภายใต้ Minor log พักมือถือจริง/NAS จริง
