# ผลตรวจรับ Module 7D Task 7 — วันจบงาน การส่งครบ และกำหนดแก้ไข

สถานะ: ผ่านผู้ตรวจอิสระและ Test, Build, Lint/Format ครบ

เพิ่มการยืนยันวันจบงานจริง การเสนอแก้วันโดยให้ผู้ตรวจอีกคนรับรอง และการยืนยัน/ถอนการส่งค่าใช้จ่ายครบ โดยเก็บประวัติและผลประเมินเวลาตามแต่ละฉบับ

## ผลงานที่ตรวจรับ

- ผู้จัดการโครงการปัจจุบันยืนยันวันจบงานครั้งแรก ใช้จำนวนวันจากฉบับคำขอที่อนุมัติ กำหนดเคลียร์และคืนเงินตรงกัน นับวันปฏิทินตาม Asia/Bangkok โดยวันถัดไปเป็นวันที่ 1
- การแก้วันต้องเสนอพร้อมเหตุผลและให้ผู้ตรวจการเงินอีกคนที่มีสิทธิ์และผ่านกติกาแยกหน้าที่ยืนยัน วันใหม่ยังไม่มีผลระหว่างรอ และข้อเสนอที่อิงฉบับเดิมซึ่งถูกแทนแล้วรับรองไม่ได้
- เจ้าของเงินยืนยันส่งครบหรือถอนพร้อมเหตุผลเป็นประวัติใหม่ ผู้ยื่นแทนทำหน้าที่นี้ไม่ได้ ต้องถอนก่อนเพิ่มร่างปกติ แต่รอบที่ถูกส่งกลับยังแก้ต่อได้ หลังปิดไม่เปิดคำขอเดิม
- เก็บเวลาส่งจากระบบ แยกการส่งครั้งแรก การส่งครบ และการแก้ไขออกจากผลอนุมัติ การรอตรวจไม่ทำให้ผู้ส่งกลายเป็นช้า
- คงกำหนดเดิมและกำหนดที่แก้ผ่านแล้วคนละค่า ไม่คำนวณหน้าต่างแก้ไขของรอบเดิมใหม่เมื่อนโยบายเปลี่ยน และไม่ลบความล่าช้าเดิม
- แก้สองกรณีจากการตรวจตัวเอง: ส่งครบครั้งแรกหลังแก้วันยังต้องแสดงผลตามกำหนดเดิม และลำดับประวัติยึดฉบับที่อ้างถึงกันแทนการเรียงเวลาซึ่งอาจย้อนกลับ
- ไม่มี schema/migration หรือ API/UI ใหม่ใน Task นี้
