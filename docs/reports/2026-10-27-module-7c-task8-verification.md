## การพบยอดหรือผู้รับผิดจากหลักฐาน

PaymentMetadataInput มีเฉพาะวันที่ เลขอ้างอิง และรหัสหลักฐาน ไม่ตีความยอดหรือผู้รับจากใบเสร็จอัตโนมัติ เมื่อผู้ใช้พบจ่ายผิด ต้องเรียก ReportMismatchAsync เดิมด้วยข้อมูลที่พบและ command แยกก่อน เพื่อบันทึกเหตุและระงับทั้งชุดในธุรกรรมเดียว จากนั้นโหลดรุ่นล่าสุดจึงแก้ metadata ต่อได้

เทสต์ครอบคลุมการรายงานเหตุ → คำสั่ง metadata รุ่นเก่าถูกปฏิเสธ → ส่งและยืนยันรุ่นใหม่ โดยยอดและผลจ่ายเดิมยังอยู่ เหตุระงับยังอยู่ และเริ่มจ่ายใหม่ไม่ได้ทั้งคำขอหลัก/ส่วนเพิ่ม ไม่มีคำสั่งปลดเหตุใน 7C

งาน API/UI ใน Task 12/13 ต้องแสดงช่องทางรายงานเหตุผิดปกติและใช้ประวัติ metadata ที่ยืนยันแล้วในการอ่านข้อมูล ไม่ถือว่าหน้าจอส่วนนี้เสร็จใน Task 8
