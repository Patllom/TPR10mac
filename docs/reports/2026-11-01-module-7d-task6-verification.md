# ผลตรวจรับ Module 7D Task 6 — ยืนยันและอนุมัติรอบค่าใช้จ่าย

สถานะ: ผ่านการตรวจอิสระและ Test, Build, Lint/Format ครบ

เพิ่มการยืนยันฉบับค่าใช้จ่ายโดยผู้รับผิดชอบเงิน และการอนุมัติหัวหน้า → ผู้จัดการโครงการ → ผู้ตรวจการเงิน โดยตรวจสิทธิ์ปัจจุบันและแยกบุคคลในแต่ละขั้น

## ผลงานที่ตรวจรับ

- Preview สำหรับเจ้าของแสดงฉบับและข้อมูลที่ต้องทบทวนโดยไม่เปลี่ยนสถานะ การส่งต้องยืนยัน hash ที่ตรงกับฉบับ กติกา และเวอร์ชันเอกสาร/หลักฐาน หากเปลี่ยนต้องทบทวนใหม่
- จัดผู้อนุมัติตามสายงานปัจจุบัน ตรวจวงเงิน ขอบเขต และข้อห้ามข้ามหน้าที่ เลื่อนระดับเมื่อชนข้อห้าม หากหาไม่ได้ให้พัก ไม่เพิ่มสิทธิ์อัตโนมัติ
- ส่งกลับทั้งรอบพร้อมเหตุผล คงยอดกันไว้ บันทึกกติกาและกำหนดแก้ไขที่ใช้ รอบแก้ไขต้องให้เจ้าของยืนยันและลงผลอนุมัติใหม่ครบทุกขั้น ไม่ใช้ผลเดิม
- อนุมัติขั้นสุดท้ายเปลี่ยนยอดกันเป็นยอดรับรองเพียงครั้งเดียว ไม่เปลี่ยนรอบเก่าที่รับรองแล้ว ตรวจคำสั่งซ้ำและเวอร์ชันภายในธุรกรรม
- คงผลอนุมัติเดิมเป็นประวัติ การตรวจสิทธิ์คำสั่งซ้ำยึดยอดของฉบับเดิม การเปลี่ยนผู้รับมอบหมายทำในธุรกรรมและย้อนกลับเมื่อคำสั่งไม่ผ่าน
- ไม่มี schema/migration หรือ API/UI ใหม่ใน Task นี้ การจัดการกำหนดส่งครบและวันจบงานเป็น Task ถัดไป
