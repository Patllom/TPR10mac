# รายงานตรวจรับ Module 7D — Task 11

ขอบเขต: สะสางเหตุจ่ายผิดและรับคืน โดยเก็บรายการจ่ายเดิมและแยกภาระเจ้าของเงินออกจากเงินผิดผู้รับ

## การเปลี่ยนแปลง

- เพิ่มการเสนอและตรวจยืนยันข้อเท็จจริงจ่ายผิด/รับคืน แยกผู้เสนอและผู้ตรวจ ตรวจสิทธิ์ปัจจุบันและคำสั่งซ้ำก่อนลงบัญชี
- ผูกเหตุระงับกับ proposal ต้นทางแบบมี FK และ unique index ทั้งสองเส้นทางของ 7C เก็บประวัติเดิมและไม่เดาความสัมพันธ์จากข้อความหรือเวลา
- ใช้ยอดจริงที่ตรวจแล้วแทนฐาน Paid ของ attempt เดียวโดยไม่บวกซ้ำ แยกคืนจากเจ้าของและคืนจากผู้รับผิดคน ยอดรอตรวจยังไม่หักหนี้
- กันยอดคืนและหลักฐานร่วมกับการคืนปกติ/แก้เงินคืน ป้องกันใช้หลักฐานหรือยอดรับคืนซ้ำ เก็บภาระบริษัทเมื่อยอดสุทธิเป็นลบ
- ไม่มีการปลดเหตุระงับ เพิ่มวงเงิน หรือสร้างงวดส่วนขาดอัตโนมัติ เตรียม events สำหรับ Task 12 เท่านั้น
- เพิ่ม migration พร้อม guard ก่อนย้อนโครงสร้าง เพื่อรักษา provenance และประวัติ มีเทสต์ฐานจำลองและ SQL ที่ตรวจได้

## หลักฐาน TDD และ regression

พบ RED จริงของ provenance, financial transitions, downgrade, proof reuse, pending capacity และสิทธิ์หมดอายุ ก่อนแก้และรันผ่าน ชุดเฉพาะสุดท้ายผ่าน 53 เคส และ regression ที่เกี่ยวข้องผ่าน 242 เคส

regression รอบแรกผ่าน 241/242: ตัวสังเกต concurrency รอเฉพาะ identity lock แต่คำสั่งต้องรอ proof lock ก่อน จึง timeout ขณะ query PostgreSQL แก้หนึ่งบรรทัดให้ใช้ตัวสังเกต lock ทั้งสองที่มีอยู่ คง barrier/assertions ยอดเงินเดิมทั้งหมด ไม่เพิ่ม timeout production ไม่เปลี่ยนจากจุด freeze แรก จากนั้น targeted และ regression ผ่าน

## ผลตรวจอิสระและข้อจำกัด

ผู้ลงมือ Erdos และผู้ตรวจ Mendel แยกกัน ผู้ตรวจให้ผ่านทั้ง spec และ quality ไม่พบ Critical/Important คง Minor T11-M1: เพิ่มเทสต์หลักฐานซ้ำระหว่าง refund correction กับ incident recovery โดยตรงไว้ตรวจรวม Task 18 กลไก production ได้รับการตรวจแล้ว ส่วน Full G มีผลจริงในตารางท้ายรายงาน

เหตุระงับเก่าที่ไม่มีต้นทาง หรือจับคู่ได้หลายเหตุจะปฏิเสธแบบ fail closed ต้องออกแบบการยืนยันต้นทางแยกก่อนใช้งาน ไม่ backfill โดยเดา การตรวจ ID/hash ของหลักฐานไม่แทนการตรวจข้อเท็จจริงของฝ่ายการเงิน

คง M2-R1/R2-C1, HTTPS 504, Minor log, OpenAPI 500, T13-M1/T14-M1 และ T4-M1 สำหรับ Task 18 พักการทดสอบมือถือจริงและ NAS จริง ไม่รวม Task 12, push, merge หรือ migration ฐานข้อมูลจริง
