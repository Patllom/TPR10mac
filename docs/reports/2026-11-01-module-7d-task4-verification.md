# ผลตรวจรับ Module 7D Task 4 — หลักฐานพนักงานและการตรวจเอกสารซ้ำ

สถานะ: ผ่าน Test, Build, Lint/Format และการตรวจอิสระครบ

เพิ่มบริการหลักฐานส่วนตัวสำหรับผู้รับผิดชอบเงินและผู้ยื่นแทน อัปโหลด/อ่านรูปหรือ PDF ตามสิทธิ์ปัจจุบัน โดยไม่สร้างประวัติผู้จ่าย ใช้ส่วนตรวจไฟล์จำกัดทรัพยากรและที่เก็บ immutable ร่วมกับ 7C แต่แยกการตรวจสิทธิ์ของหลักฐานพนักงาน

## ผลงานที่ตรวจรับ

- ลงทะเบียนเอกสารด้วยผู้ออก เลขที่หรือไม่มีเลข วันที่ ยอด และหลักฐานหลายไฟล์ ตรวจขอบเขตและข้อมูลไฟล์ซ้ำหลัง I/O และก่อนบันทึก ไม่เปิด URL สาธารณะ
- ตรวจซ้ำทั้ง hash ไฟล์และข้อมูลเอกสาร โดยปรับรูปแบบยอดให้เป็นมาตรฐานเดียวกัน เช่น 123.4 กับ 123.40 ไม่หลุดการเปรียบเทียบ
- เอกสารสงสัยซ้ำข้ามคำขอถูกพัก ผู้ตรวจต้องมีสิทธิ์ทั้งสองโครงการและผ่านการแยกหน้าที่ทั้งสองชุด ผู้ยื่นไม่เห็นข้อมูลคำขออื่น
- ผลตรวจผูกเวอร์ชันเอกสาร การแก้ข้อมูลสำคัญสร้างการตรวจใหม่และคงประวัติเดิม ถอนสิทธิ์แล้วไม่สามารถเรียกผลเดิมซ้ำเพื่อข้ามข้อห้าม
- ล็อกทะเบียนก่อน family และ request ตามลำดับคงที่ เพื่อให้การลงทะเบียนพร้อมกันไม่ข้ามการตรวจซ้ำ
- ปรับ index เฉพาะคู่เอกสาร/เวอร์ชันให้คำสั่งหนึ่งสร้างคู่สงสัยได้หลายคู่ มี EF migration/designer/snapshot จริง ไม่มีการรัน migration ฐานจริง

## การตรวจและจุดที่แก้จาก Review

ผู้ลงมือ Hypatia และผู้ตรวจ Lorentz แยกกัน ตรวจข้อกำหนดและคุณภาพโค้ด รวมการตรวจซ้ำเฉพาะรอบแก้

ผู้ตรวจพบล็อกทะเบียนใช้หมายเลขเดียวกับ CSRF จึงแยกเป็นหมายเลขเฉพาะ และเพิ่ม regression ที่เรียก production service กับ PostgreSQL สอง connection พิสูจน์ RED ก่อนแก้และ GREEN หลังแก้ โดยไม่เปลี่ยนล็อก CSRF เดิม รอบแก้ผ่าน 16 เคสและผู้ตรวจรับรอง

ชุด Format ทั้งโครงการพบ whitespace ที่ filtered check เดิมไม่ครอบคลุม จึงจัดรูปแบบ 3 ไฟล์ ตรวจด้วย Roslyn ว่า token/string/comment/directive ทั้ง 15 ไฟล์ไม่เปลี่ยน แล้วตรวจ Full Format ผ่านและ focused tests 25 เคสผ่าน ผู้ตรวจรับรองรอบแก้นี้ด้วย

ชุดเฉพาะส่วนก่อนรอบแก้ผ่าน 106 เคส รวม regression ของหลักฐานเดิม; ชุดเต็มสุดท้าย Backend ผ่าน 3158 เคส และ Frontend 178 เคส ไม่มีเทสต์ล้มเหลว
