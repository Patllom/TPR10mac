## สิ่งที่พัฒนา

เพิ่มหน้าปรับวงเงินก่อนจ่าย หน้าคำขอส่วนเพิ่มหลังจ่าย และหน้าตัดสินใจกลับเงื่อนไขเดิมหรือยุติยอดที่ยังไม่จ่าย โดยใช้สิทธิ์ปัจจุบันจากเซิร์ฟเวอร์ โครงการและผู้รับผิดชอบเงินของส่วนเพิ่มถูกล็อกตามต้นเรื่อง แยกยอดส่วนเพิ่มที่จ่ายได้ออกจากฐานอำนาจอนุมัติสะสม แสดงข้อมูลฐานรวมเฉพาะที่ API อนุญาต การเห็นคำขอส่วนเพิ่มไม่ทำให้เห็นข้อมูลต้นเรื่องโดยอัตโนมัติ

ก่อนเปิดใช้วงเงินแก้ไข ต้องอนุมัติฉบับใหม่และสะสางงวดเดิมครบทั้งสองเงื่อนไข หากผลจ่ายไม่ชัดเจนให้พัก ส่วนเพิ่มที่ส่งกลับหรือพักยังถือว่าค้าง คำขอเดิมจ่ายต่อได้ตามเหตุระงับและสิทธิ์เดิม แต่ส่วนเพิ่มจ่ายไม่ได้ก่อนอนุมัติ หากยอดประเมินเปลี่ยนต้องให้ผู้รับผิดชอบยืนยันใหม่

การยุติยอดแสดง “ยุติเฉพาะยอดที่ยังไม่จ่าย ยังต้องเคลียร์เงินที่จ่ายแล้ว” ไม่ปิดคำขอทางการเงินหรือหักฐานอนุมัติย้อนหลัง การกลับเงื่อนไขเดิมไม่ล้างเหตุยอดไม่ตรง และไม่มีการเพิ่มสิทธิ์เพื่อแก้กรณีหาผู้ยืนยันไม่ได้

ขยายข้อมูลอ่าน payment-context และตัวแปลงข้อมูลฝั่ง client เท่าที่หน้าจอต้องใช้ ผู้มีเฉพาะการมอบหมายตัดสินใจเห็นข้อมูลจำกัด ไม่มีบัญชี งวด หลักฐาน หรือรายละเอียดต้นเรื่อง คงการตรวจสิทธิ์และข้อมูลซ้ำก่อนส่งผลตอบกลับ ค่าเริ่มต้นของการอ่านเดิมและการตรวจธุรกรรมยังอยู่ ไม่เปลี่ยน schema หรือเพิ่มสิทธิ์อัตโนมัติ
