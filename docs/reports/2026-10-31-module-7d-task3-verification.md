# ผลตรวจรับ Module 7D Task 3 — สิทธิ์และธุรกรรมคำสั่งเคลียร์

สถานะ: ผ่าน Test, Build, Lint/Format และการตรวจอิสระครบ

เพิ่มบริการ SettlementAccess, SettlementCommandExecutor และรายการ action ที่ระบุชัดเจน เพื่อให้บริการเคลียร์เงินใช้สิทธิ์ปัจจุบันและธุรกรรมร่วมกัน ปฏิเสธ action ที่ไม่รู้จัก ไม่เพิ่มสิทธิ์อัตโนมัติให้ผู้ดูแลระบบหรือทีม

## พฤติกรรมที่ตรวจรับ

- ตรวจบัญชีและบุคคลปัจจุบัน สิทธิ์รายโครงการ ประวัติหน้าที่ทั้งชุดคำขอ และขั้นอนุมัติที่ได้รับมอบหมาย ก่อนคืนผลคำสั่งซ้ำ
- คำสั่งเดิมที่เปลี่ยนข้อมูล ผู้กระทำ หรือเป้าหมายคืน conflict; การถอนสิทธิ์ทำให้เรียกผลเดิมซ้ำไม่ได้
- ล็อก family → request → entity โดยตรวจขอบเขตเป้าหมายก่อนล็อก ไม่รอแถวของคำขออื่นที่ไม่มีสิทธิ์
- บันทึกข้อมูล ยอด ประวัติการทำหน้าที่ audit และผลคำสั่งในธุรกรรมเดียว ตรวจสิทธิ์ซ้ำก่อน commit; ความล้มเหลวต้องย้อนกลับทั้งหมด
- เจ้าของและผู้ยื่นแทนไม่ถูกบันทึกเป็นผู้จ่ายจากการเตรียมเคลียร์ เจ้าของเป็นผู้ยืนยัน
- เคสปรับปรุงหลังปิดทำแยกจากคำขอเดิม ไม่เปิดหรือเปลี่ยนเวอร์ชันคำขอเดิม การพยายามแก้ข้อมูลเดิมใน callback ต้อง rollback
