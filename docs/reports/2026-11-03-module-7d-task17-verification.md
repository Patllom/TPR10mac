# ผลตรวจ Module 7D — Task 17: หน้าผู้อนุมัติและฝ่ายการเงิน

สถานะ: Task 17 ผ่านการตรวจรับ ผู้ลงมือและผู้ตรวจแยกคน แก้ Important ครบ และชุดตรวจเต็มผ่านบนโค้ดสุดท้าย; Task 18 ยังไม่เริ่ม

## สิ่งที่เพิ่ม

เพิ่มคิวงานตามโครงการและหน้าที่ พร้อมหน้าตรวจรอบค่าใช้จ่าย คืนเงิน ปรับปรุงรายการ และสะสางเหตุจ่ายผิด แยกการยืนยันข้อเท็จจริง รับคืน ปลดเหตุระงับ และเตรียมส่วนขาดเป็นคนละคำสั่ง ใช้สิทธิ์และสถานะจากเซิร์ฟเวอร์ ไม่เพิ่มสิทธิ์อ่านการเงินอัตโนมัติ

เติม API อ่านข้อมูลที่จำเป็นต่อหน้าผู้ตรวจ ได้แก่ คิวที่ได้รับมอบหมาย ข้อมูลตามรายการ เอกสารสงสัยซ้ำภายใต้สิทธิ์ทั้งสองคำขอ และหลักฐานที่ตรวจสิทธิ์ก่อนส่งจริง ไม่มี schema/migration หรือการเปลี่ยนกติกาสิทธิ์

รองรับคิวและรายชื่อโครงการหลายหน้า ล้างข้อมูลที่ป้องกันเมื่อเสียสิทธิ์ และมีพื้นที่ตรวจผลคำสั่งค้างแยกจากรายการที่ยังอยู่ในคิว เมื่อไม่ทราบผลจะคงรหัสเดิมและไม่ส่ง POST อัตโนมัติ ไม่เก็บรายละเอียดการเงินถาวรใน browser

## การตรวจอิสระ

ผู้ลงมือ Chandrasekhar; ผู้ตรวจ Euclid พบ Important 6 ข้อในรอบแรก: cursor, การล้างข้อมูลเมื่อเสียสิทธิ์, การผูก receipt กับชนิดคำสั่ง, การกู้ผลหลังรายการออกจากคิว, browser multiple-hold และการโหลดโครงการหน้าถัดไป รอบแก้ที่ 1 ผู้ตรวจยืนยัน ADDRESSED ครบ 6 ข้อ ไม่พบ Critical/Important ใหม่

เทสต์ receipt variant บางส่วนเป็น helper tests ที่เพิ่มหลังแก้ ไม่มี RED แยก และไม่อ้างว่าเป็น HTTP matrix ครบทุก variant บันทึกขอบเขตนี้ตามจริง

## หลักฐานและข้อจำกัด

HTTPS รอบแก้ผ่าน 7 กรณีทั้ง dev 4000 และ production 4001 โดย build หลัง dev หยุด หลักฐานอยู่ใน scratch `.superpowers/sdd/2026-10-31-module-7d-settlement-refunds/` และ `/tmp/7d-t17-evidence/` ซึ่งต้องเก็บก่อนล้างเครื่อง

ประวัติการตรวจ hash ระหว่าง HTTPS ครอบคลุม 31 ไฟล์และตกหล่น settlement-view.ts; ผู้ลงมือให้หลักฐานเวลาและ manifest ปัจจุบัน 32 ไฟล์ ผู้ประสานงานตรวจ 32 ไฟล์ก่อนชุดเต็ม ไม่อ้างว่าจุดตรวจประวัติเป็น 32/32

การทดสอบส่วนเพิ่มใช้ API/หน้าเว็บจริง แต่ seed สถานะปิดและรายการปรับปรุงในฐานจำลอง ไม่ใช่หลักฐานธุรกรรมปิดคำขอครบทุกเงื่อนไขหรือการจ่ายเงินจริง

คง T17-M1: เพิ่ม positive-byte และ delivery-revocation test ผ่าน work-proof route โดยตรง; T17-M2: แปล raw status/source labels ในหน้าผู้ตรวจเป็นไทยให้ครบ

คงรายการติดตามเดิม M2-R1/R2-C1, HTTPS 504, Minor log, OpenAPI 500, T13-M1/T14-M1, T4-M1/T11-M1 สำหรับ Task 18, T12-M1/T13-REVIEW-M1/T14-REVIEW-M2/T15-REVIEW-M1, T15-REVIEW-M2, T16-M1/T16-M2 และ production worker EF-wrapper resiliency ไม่อ้างว่าปิดจากผลเทสต์ครั้งนี้

พักมือถือจริงและ NAS จริง ไม่มี deploy/migrate ข้อมูลจริง/push/merge และยังไม่เริ่ม Task 18 งาน HTTPS 504 เดิมคงไว้แยกจาก commit นี้
