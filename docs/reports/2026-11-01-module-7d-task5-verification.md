# ผลตรวจรับ Module 7D Task 5 — ร่างค่าใช้จ่ายและการจัดสรรยอดเอกสาร

สถานะ: ผ่านการตรวจอิสระและ Test, Build, Lint/Format ครบ

เพิ่มบริการบันทึกร่างค่าใช้จ่ายเป็นฉบับใหม่โดยรักษาประวัติ และบริการกันยอดเอกสารภายในธุรกรรม รองรับหลายรายการและหลายรอบในคำขอเดียวกัน

## ผลงานที่ตรวจรับ

- หมวดและอัตรายึดฉบับคำขอที่อนุมัติ คำนวณและปัดรายรายการตาม SettlementMath ไม่ใช้กติกาปัจจุบันแทน ร่างเกินวงเงินบันทึกได้ แต่ไม่เปลี่ยนยอดรับรองหรือวงเงินจ่าย
- ร่างทั่วไปยังไม่กันยอด การกันยอดใช้บริการภายใน executor เมื่อยืนยัน โดยตรวจว่าเป็นฉบับล่าสุดและผู้มีสิทธิ์ปัจจุบัน รอบส่งกลับคงยอดกัน ลดหรือลบคืนเฉพาะส่วนต่าง เพิ่มยอดต้องตรวจวงเงินเอกสารอีกครั้ง
- รวมยอดเอกสารที่รับรองและกันไว้เพียงครั้งเดียว ตรวจคำขอเดียวกัน ไฟล์ Ready และผลตรวจซ้ำที่ตรงเวอร์ชัน ภายใต้ล็อกทะเบียนก่อน family/request ในธุรกรรมเดียวกัน
- เพิ่มชนิดหลักฐานที่ผู้ยื่นระบุในข้อมูลเอกสาร เทียบกับประเภทที่หมวดในฉบับอนุมัติยอมรับ รองรับชนิดภาษาไทยและชนิดที่บริษัทกำหนด เอกสารเก่าไม่มีชนิดยังอ่านได้ แต่ต้องระบุก่อนส่งตรวจ ไม่เดาจากไฟล์
- แก้ข้อมูลเอกสารได้เมื่อทุกการอ้างอิงเป็นร่างที่ยังไม่ยืนยันหรือส่งตรวจเท่านั้น ถ้าเคยกันยอด ส่งตรวจ หรือรับรองแล้ว ยังห้ามแก้ โดยเก็บกติกาเวอร์ชันและตรวจซ้ำเดิม
- SourceLineId อ้างรายการค่าใช้จ่ายของฉบับก่อนหน้าในรอบเดียวกันตาม FK เดิม ไม่มีการเปลี่ยน schema/migration ไม่มี endpoint/UI ใหม่ใน Task นี้
